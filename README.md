# Laughing Tree — React (Vite) website

## Run
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production files in /dist

## Edit
- Text, phone, email, services, gallery: `src/data.js`
- Section layout: `src/components/`
- Colours & fonts: top of `src/index.css` (`:root` variables)
- Photos: `public/images/`

## Luxury redesign notes
- Services' hover panels, details chapters: `src/data.js` (`SERVICES`, `DETAILS`)
- Palette & fonts: `:root` at the top of `src/index.css` (Bodoni Moda + Hanken Grotesk)
- Hero video: `public/laughing-tree-hero.mp4` (portrait works best)
